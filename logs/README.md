# Log forward test

Folder ini belum berisi `raw_forward_test.json` karena ekspor yang tersedia belum membuktikan kelengkapan periode forward test 10 hari. Jangan membuat atau mengisi log sintetik.

Setelah periode yang benar-benar tercatat diekspor dari dashboard Vercel, simpan file ekspor mentah di sini beserta waktu ekspor dan jangan mengubah isinya. Ekspor API saat ini dapat memiliki batas retensi; jika `logExportComplete` bernilai `false`, jangan menyebutnya log lengkap.

Data yang diperlukan menurut soal: seluruh panggilan dan error, sinyal per pair/candle, order dan trade simulasi, equity harian, snapshot order book mentah, serta event kill switch.
